ППО ID Docs — архитектурные схемы

Портфолио-группировка Territory / Rexoft. В доступных технических материалах система обозначена как ППО ID Docs. Схемы показывают документированные сведения отдельно от логических связей и вопросов, требующих проверки.

1. Контекст и границы обмена

  MS -->|"Direct SQL calls — documented"| DB
  SERVICE_A ---|"JSON format documented; participants and direction unspecified"| SERVICE_B
Подтверждено исходными материалами: прямые SQL-запросы АРМ МС Подтверждено исходными материалами: JSON между сервисами Логическая реконструкция: участники обмена не идентифицированы

Схема намеренно не задаёт направление JSON-обмена и не соединяет клиентские рабочие места с конкретными сервисами: доступные материалы не устанавливают участников, направление и полный граф вызовов. Роль USB-модуля и сценарий синхронизации показаны раздельно, без неподтверждённой стрелки вызова.

Семантика схемы: пунктирные стрелки обозначают только классификацию таблиц по группам. Они не обозначают внешние ключи, связи между таблицами, зависимости компонентов или потоки данных.

Арифметическая проверка: 44 + 104 + 11 + 10 + 17 + 8 + 207 = 401. Равенство подтверждает внутреннюю согласованность приведённых чисел, но не доказывает, что распределение совпадает с фактическим каталогом Oracle.

Отдельная физическая спецификация содержит 381 пронумерованную позицию. Это отдельный документальный источник; диаграмма не пытается свести оба числа к одному.
