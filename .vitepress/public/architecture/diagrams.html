ППО ID Docs — архитектурные схемы

Портфолио-группировка Territory / Rexoft. В доступных технических материалах система обозначена как ППО ID Docs. Схемы показывают документированные сведения отдельно от логических связей и вопросов, требующих проверки.

1. Контекст и границы обмена

flowchart LR
  MS["ПО МС / АРМ МС"]
  DB[("Oracle information database")]
  SERVICE_A["Service participant A"]
  SERVICE_B["Service participant B"]
  USB["Umms.UsbExchange"]
  DICT["Dictionary synchronization"]

  MS -->|"Direct SQL calls — documented"| DB
  SERVICE_A <-->|"JSON format documented; participants unspecified"| SERVICE_B
  USB -.->|"Module role documented"| DICT
Подтверждено исходными материалами: прямые SQL-запросы АРМ МС Подтверждено исходными материалами: JSON между сервисами Логическая реконструкция: участники обмена не идентифицированы

Схема намеренно не соединяет клиентские рабочие места с конкретными сервисами: доступные материалы не устанавливают полный граф вызовов.
