Статус данных: числа воспроизводят инвентаризацию в доступных материалах; сверка с исходным каталогом Oracle не выполнена.
Семантика: пунктирные стрелки обозначают только классификацию таблиц по группам. Они не обозначают внешние ключи, связи между таблицами, зависимости компонентов или потоки данных.

Арифметическая проверка: 44 + 104 + 11 + 10 + 17 + 8 + 207 = 401. Арифметика сходится. Это подтверждает внутреннюю согласованность чисел, но не доказывает фактическое распределение всех таблиц в каталоге Oracle.

Статус: значения групп приведены в существующей документации; сверка полного состава и распределения с исходным каталогом Oracle требует дополнительной проверки.
