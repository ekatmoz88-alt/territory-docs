## Evidence and limitations

ППО ID Docs — реальная информационная система, развёрнутая и работавшая в офисной серверной инфраструктуре. Публичная документация подготовлена на основе проектных материалов, описаний системы и исходного кода. Архитектурные схемы отражают документированную систему и отдельно помечают логические связи, которые нельзя вывести напрямую из доступных артефактов. Отсутствие доступа к офисному серверу с персонального ноутбука не означает отсутствия реальных API-маршрутов или работающих операций.

Инвентаризация информационной базы указывает 401 таблицу. Отдельный документ физической структуры содержит 381 пронумерованную позицию; значения относятся к разным документальным источникам и не подменяют друг друга.
