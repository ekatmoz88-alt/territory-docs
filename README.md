[English](README.en.md) | [Русский](README.md)

Репозиторий `territory-docs` содержит техническую документацию по информационной базе и прикладным компонентам ППО ID Docs: модели Oracle, предметные модули паспортного и миграционного учёта, исходный код, API и связи между ними.

- [База данных и модели](./database/index.md) — структура Oracle DB, таблицы ядра и справочников, предметные группы и ER-материалы.
- [Исходный код и модели](./source-code/index.md) — структура проектов, основные компоненты и соответствие моделей кода таблицам БД.
- [API и операции](./api/index.md) — JSON-операции, поля запросов, сопоставление с таблицами БД, валидация и откат.

## Evidence and limitations

Материалы основаны на доступной проектной документации и выбранных фрагментах исходного кода. Архитектурные схемы являются логическими представлениями и не должны трактоваться как подтверждённая схема production-развёртывания. Операции и сопоставления полей не являются доказательством доступности или успешного выполнения runtime API.

Инвентаризация информационной базы указывает 401 таблицу. Отдельный документ физической структуры содержит 381 пронумерованную позицию; значения относятся к разным документальным источникам и не подменяют друг друга.
