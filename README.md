Репозиторий содержит техническую документацию по информационной базе и прикладным компонентам ППО ID Docs: модели Oracle, предметные модули паспортного и миграционного учёта, исходный код, API и связи между ними.

**Граница проекта:** ППО «Территория» ФМС — отдельная система, документируемая в [ppo-territory-archive](https://github.com/ekatmoz88-alt/ppo-territory-archive). Материалы двух систем, их базы данных и интеграции не объединяются.

## Evidence and limitations

Материалы основаны на доступной проектной документации и выбранных фрагментах исходного кода. Архитектурные схемы отделяют подтверждённые сведения от логической реконструкции и вопросов, требующих дополнительной проверки. Они не являются подтверждённой схемой production-развёртывания. Описание API и сопоставления полей не доказывают доступность live runtime endpoints или успешное выполнение операций.

Инвентаризация информационной базы указывает 401 таблицу. Отдельный документ физической структуры содержит 381 пронумерованную позицию; значения относятся к разным документальным источникам и не подменяют друг друга.
