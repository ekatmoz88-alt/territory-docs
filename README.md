# ППО «Территория» — техническая документация

> **📘 Documentation website:** [Open Territory Docs](https://ekatmoz88-alt.github.io/territory-docs/)

Репозиторий `territory-docs` содержит детализированные материалы по информационной базе и прикладным компонентам ППО «Территория»: модели Oracle, предметные модули паспортного и миграционного учёта, исходный код, API и связи между ними. Это дополнительный комплект технической документации по ППО «Территория», а не описание отдельной самостоятельной системы. АРМ «Дискриптор» (`descriptor-arm-spec`) рассматривается отдельно; его нельзя считать частью ППО «Территория» без подтверждения архитектурной связи.
