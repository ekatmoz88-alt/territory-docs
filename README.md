# ППО «Территория» — архив документации

Материалы этого репозитория объединены в каноническом проектном хабе **ППО «Территория» / «Дешифратор» / UMMS**.

- [Каноническая документация](https://ekatmoz88-alt.github.io/territory-descriptor-unified/)
- [Oracle database, data model and API](https://ekatmoz88-alt.github.io/territory-descriptor-unified/materials/territory-database/)
- [Repository source](https://github.com/ekatmoz88-alt/territory-descriptor-unified)

Уникальные сведения из прежних документов перенесены в канонический хаб. Повторные копии больше не поддерживаются. Этот репозиторий оставлен как указатель для старых ссылок. Корневая и известные прежние адреса разделов настроены на перенаправление к каноническому хабу или соответствующим файлам в нём; репозиторий больше не содержит отдельную копию документации.
