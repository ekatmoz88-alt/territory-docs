# ППО ID Docs — архитектура, база данных, API и исходный код

Комплект технической документации по ППО ID Docs охватывает логическую архитектуру, информационную базу Oracle, предметные модули учёта, программные компоненты и API-операции.

## Навигация по разделам

- [Архитектура системы](./architecture/) — системный контекст, границы, программные компоненты, модель данных и потоки операций с явными статусами доказательности.
- [База данных и модели](./database/index.md) — структура БД Oracle, ядро (`CORE_*`), справочники (`DICT_*`), предметные модули, связи и ER-материалы.
- [Исходный код и модели](./source-code/index.md) — архитектура проектов (`Umms.*`), основные модули ПО СС/ПО МС, сценарии и сопоставление моделей кода с таблицами БД.
- [API и операции](./api/index.md) — реальные API-маршруты и операции системы, JSON-обмен, прикладной код и сопоставления с БД; публичная документация не раскрывает закрытые конфигурации и полный внутренний контракт.

## Общая информация

В доступных материалах информационная база ППО ID Docs описана как предназначенная для автоматизации учёта граждан, документов, регистрации и миграции. Документальная инвентаризация указывает 401 таблицу: 44 таблицы ядра `CORE_*`, 104 таблицы справочников `DICT_*`, остальные отнесены к предметным модулям. Полная сверка этого распределения с исходным каталогом Oracle не выполнена.

- **Формат обмена:** JSON между сервисами; для работы АРМ МС в материалах также описаны прямые SQL-запросы к БД.
- **Поле VERSION:** встречается в отдельных описаниях таблиц; наличие и назначение следует проверять для каждой таблицы отдельно.

## Ограничения

Система была развёрнута и работала в офисной серверной инфраструктуре. Документация отражает реальный исторический проект. Повторная проверка текущего состояния серверов в рамках подготовки публичного портфолио не выполнялась. Логические схемы не претендуют на реконструкцию физической топологии каждой установки; закрытые конфигурации и детали интеграций не публикуются.
