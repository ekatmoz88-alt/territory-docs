## Общая информация

Информационная база системы паспортного учёта предназначена для автоматизации учета граждан, документов, регистрации и миграции. 
Модель реализована в Oracle, включает 401 таблицу (44 таблицы ядра `CORE_*`, 104 таблицы справочников `DICT_*`, остальные относятся к модулям предметной области).

- **Формат обмена**: JSON (при обмене между сервисами), прямые SQL-запросы к БД (при работе АРМ МС).
- **Версия API**: 1.0
- **Оптимистическая блокировка**: Используется поле `VERSION` (NUMBER) во всех таблицах ядра и миграции.
